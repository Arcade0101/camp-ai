Camp AI is an open-source project that helps teachers find schedules, meeting points, and preparation instructions in the documents their coordinator shares.

See how Camp AI works

How it works

For coordinators
Create a camp, upload its documents, and share a camp link with teachers. Add an access code when needed.
For teachers
Open the link on your phone and ask a question without creating an account. Answers cite the camp documents they use.

The landing page is available now. Coordinator tools and teacher chat are planned for later phases.
