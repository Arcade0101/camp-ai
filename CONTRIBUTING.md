# Contributing to Camp AI

Use the Node.js version and setup in the [README](README.md). Work on a branch and keep each change focused on the current milestone. Describe what changed, why it matters, and how you verified it in your pull request.

Run lint, type checking, formatting checks, and the production build before opening a pull request. For interface changes, also check a narrow phone layout and a desktop layout. Use fictional camps in examples and keep credentials, student data, and private documents out of the repository.
