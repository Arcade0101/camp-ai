# Security policy

If you find a vulnerability in a published repository, use GitHub's private vulnerability reporting when enabled. Otherwise, ask a maintainer for a private reporting channel before sharing technical details. Include affected versions, expected and observed behavior, and reproduction steps using fictional data. Keep secrets and real camp records out of reports.

Phase 1 only serves a static landing page. The MVP will need verified camp isolation, private storage, teacher session checks, and bounded uploads and chat requests before processing real camp data. Supabase elevated credentials and Gemini keys belong on the server.
